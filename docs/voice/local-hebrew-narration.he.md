# הקראת מתכון בעברית בדפדפן

בחלונית ליווי הבישול, „הקרא את השלב” מקריא את ההוראות ו„הקראת התשובה” מקריא תשובה לשאלה שהוקלדה. העוזר מקריא תשובות לשאלות קוליות באופן אוטומטי. ברירת המחדל במכשיר שיש בו קול מערכת עברי מקומי היא להשתמש בו ללא הורדה. אפשר לבחור גם בנועה.

## מה מורידים

נועה משתמשת ב־ReNikud כדי להפוך עברית לא מנוקדת לרצף הגאים ובהם ההטעמה, וב־Piper כדי ליצור שמע בקצב 22,050 דגימות לשנייה. שניהם רצים במעבד של המכשיר באמצעות WebAssembly ב־Web Worker. חבילת נועה כוללת 112,006,555 בתים, מהם 77,056,101 למודל הקול ו־20,620,594 למודל ההגייה. קובצי המודל יורדים מ־Hugging Face בעקבות לחיצה על כפתור ההורדה. הטקסט להקראה נשאר בדפדפן. אפשר לבטל את ההורדה, לחדש אותה תוך שימוש בקבצים שלמים שכבר אומתו, ולמחוק את החבילה.

## הפעלת שיחה רציפה

בסוף הוראות ההכנה לוחצים על „התחלת ליווי קולי” ומאשרים גישה למיקרופון. בהפעלה הראשונה יורדים הקבצים החסרים לתמלול, להבנת המתכון ובמידת הצורך לקול נועה. אפשר לבטל בזמן הטעינה. העוזר מקריא את השלב הנוכחי, מציג את המילים תוך כדי דיבור ומעביר משפט לעוזר לאחר הפסקה בדיבור. בזמן ההקראה המיקרופון מושתק. לאחר סיומה אפשר לדבר שוב, גם כשהחלונית מצומצמת. „עצירת הליווי הקולי” או יציאה מהמסך משחררות את המיקרופון.

„הצגת פרטי הליווי ואפשרויות נוספות” פותח את הניווט, ההקלדה וניהול ההורדות. בדפדפן שתומך בהקלטה אך חסרה בו תמיכה בתמלול רציף, אפשר להקליט משפט בודד.

## שחזור בדיקת ההקראה הידנית

1. פותחים מתכון בדפדפן בפרופיל נקי, ב־HTTPS או ב־localhost. מציגים את פרטי הליווי, פותחים „קול להקראה בעברית”, מורידים את נועה, מבטלים ומחדשים את ההורדה.
2. מורידים גם את התמלול העברי, מרעננים את העמוד ומפעילים את עוזר המתכון. לאחר שהעוזר זמין, מעבירים את הדפדפן למצב לא מקוון.
3. לוחצים על „הקרא את השלב”. לבדיקה של שברים ומספרים אפשר להשתמש בהוראה „להוסיף ½ כוס מים לקערה”. בודקים גם עצירה באמצע משפט ומעבר לשלב הבא.
4. מקלידים „מה השלב הנוכחי?” ומפעילים „הקראת התשובה”. לאחר מכן מקליטים דיווח על המתכון ומסיימים את ההקלטה. בודקים שהתשובה מוקראת ושהמיקרופון סגור לאורך ההקראה.
5. מוחקים את נועה ומוודאים שהתמלול והעוזר עדיין זמינים. במכשיר ללא קול מערכת עברי מקומי נשארים כפתורי הניווט והטקסט.

## היקף האימות

הבדיקה הורצה בגרסת ייצור של Next.js ב־Chromium 156 על Linux x86-64. נתוני המתכון והמיקרופון הודמו. קובצי המודלים, הפענוח, יצירת השמע והפעלת Web Audio היו אמיתיים. דוגמת השמע נלקחה מהנתונים שנמסרו לנגן בעמוד המתכון. בדיקת שימוש בטלפון פיזי ובדיקת האזנה של דוברי עברית עדיין פתוחות.

[האזנה לדוגמת שלב במתכון](hebrew-noa-step.wav)

בהרצה עם מודלים שמורים בדפדפן ועוזר מתכון פעיל, עברו 3.24 שניות מהלחיצה הראשונה ועד תחילת הנגינה. סכום ה־RSS של תהליכי התצוגה של Chromium עלה מכ־695 לכ־1,020 MiB במהלך הקראת השלב. הנתון כולל את הדף, העוזר, ה־worker והנגן, ועשוי לספור זיכרון משותף יותר מפעם אחת. זו מדידה אחת במחשב. טרם נמדדו השהיה וצריכת זיכרון ב־Android או ב־iPhone.
