הפעלת טיימר

איך בודקים?

  1. הפעילו טיימר, וודאו שמופיע ״התראה נקבעה במכשיר״.
  2. נעלו את המסך והמתינו להתראה.
  3. חזרו על הבדיקה במצב טיסה.
  4. בדקו שהשהיה וביטול מונעים את ההתראה, והמשך קובע זמן סיום חדש.

זהו מסך בדיקה מקומי. האתר המלא עדיין דורש חיבור לאינטרנט. התראה אינה עוקפת מצב שקט, Focus או הגבלות מערכת.
