# רמזי תמלול לשמות מצרכים המורכבים משתי מילים

**החלטה. להמשיך עם רמזי המילים הבודדות כמועמד לבדיקת תיקונים.** במבחן התיקונים הם שיפרו גם את זיהוי המילים שמחוץ למתכון. במבחן הראשון צירופים מלאים החזירו את ״שמן זית״ בשתי רמות רעש של אותה הקלטה אנושית. בקבוצה זו שאר מופעי ״שמן זית״ לא השתפרו, ו״פלפל שחור״ נשאר חסר בכל שלוש גרסאות המשפט המלאכותי. הוספת הצירופים למילים הבודדות הניבה בדיוק את אותם תמלילים כמו מילים בודדות בכל 78 הקלטים. אין ראיה ששילוב שתי הרשימות נותן יתרון נוסף.

| מדד | ללא רמזים, beam4 | מילים בודדות | צירופים מלאים | שתי הרשימות |
|---|---:|---:|---:|---:|
| אזכורי צירופים ששוחזרו במדגם הראשון | 8/14 | 8/14 | 10/14 | 8/14 |
| שגיאות מילים במדגם הראשון, 1,030 מילות ייחוס | 427 | 425 | 424 | 425 |
| שגיאות מילים ב־18 הקלטות התיקונים, 114 מילות ייחוס | 17 | 10 | 13 | 10 |
| שמות חלופיים שנשמרו בהקלטות התיקונים | 11/18 | 15/18 | 12/18 | 15/18 |
| אזכורים עודפים של אחד משלושת צירופי המתכון בשני המדגמים | 0 | 0 | 0 | 0 |

לדוגמה, במשפט של נועה ״עוד לא שמתי שמן זית, שמתי שמן קנולה״ התקבל ללא רמזים ״עוד לא שמתי שם על זית, שמתי שמן קנולה״. רמזי המילים הבודדות החזירו את המשפט הנכון. בדוגמה ״הוספתי רוטב סויה וקצת פלפל לבן״ רמזי המילים הבודדות החזירו את שני המצרכים בכל שלושת הקולות. הספירה של ״שמן קנולה״ נשארה 3/6 בכל שלוש גרסאות beam4 עם רמזים וגם ללא רמזים. המדגם הקטן והקולות המלאכותיים מגבילים את ההכללה. הרצת הצירופים ותיקוני הדיבור בוצעה ב־Chromium על Linux. דיבור ספונטני וטלפון פיזי עדיין דורשים מדידה. [פלט ההשוואה](results.json) · [פלט התיקונים](correction-results.json) · [שילוב הרמזים](combined-results.json) · [השילוב בתיקונים](combined-corrections.json)


הרמזים נלקחו משלושה מצרכים במתכון הפסטה שבבדיקות מפרש המתכונים. השווינו את המילה הראשונה של כל שם (״רוטב״, ״שמן״, ״פלפל״) לשם המלא (״רוטב עגבניות״, ״שמן זית״, ״פלפל שחור״). בכל התנאים הוזן האודיו המקורי או התערובת עם הרעש, ללא RNNoise. ארבעת הפענוחים בוצעו בדפדפן בענן. כל הגדרות החיפוש זהות בין שתי זרועות הרמזים. גם הכמות וגם הפועל אינם חלק מרשימת הרמזים. [המתכון במאגר](../../../../tests/unit/lib/recipes/parser.test.ts) · [תוכנית הניסוי](PLAN.he.md)

60 הקלטות ותנאי רעש נוצרו מ־24 קובצי דיבור. הם כוללים את שש הקלטות הקריאה על אוכל, שישה דיווחי בישול מלאכותיים (אחד מהם ״שמתי פלפל שחור. סליחה, פלפל אדום״), ו־12 הקלטות ממדגם הקריאה השני. אלה חומרי פיתוח מוכרים. ההחלטה לבדוק שמות מורכבים באה בעקבות הטעות שנצפתה ב״שמן זית״. כמה מההקלטות בכוונה אינן עוסקות במתכון הפסטה. תערובות הרעש ואופן ההכנה מפורטים [בניסוי הקודם](../rnnoise/README.he.md).

המדד סופר התאמה מלאה של צירוף, כולל תחיליות עבריות על המילה הראשונה. הוא סופר בנפרד אזכור עודף מול תמליל הייחוס. מילה אחת מהצירוף אינה מספיקה. תמלילי שלילה נבדקים גם לפי מספר מופעי ״לא״ ו״ולא״. המדדים המילוליים אינם בודקים אם עדכון מצב מתכון היה מוצדק.

## שחזור

משתמשים בתיקיות הקלט משחזור ניסוי RNNoise. פקודת ההכנה ממפה את קובצי השמע המקומיים ובודקת את טביעותיהם. בממשק הקיים של מנוע הניסוי, המשבצת salad מכילה את המילים הבודדות והמשבצת cookies את הצירופים. הבדיקה משתמשת רק במשקולות ASR, במילון BPE הקיים ובשורות הרמזים.

```sh
python prepare.py /tmp/he-filter-trial /tmp/he-filter-confirm /tmp/he-phrase-fixtures
SPEECH_RECIPE_HINTS=1 SPEECH_MANIFEST=/tmp/he-phrase-fixtures/manifest.json \
  SPEECH_NEW_CACHE=/tmp/he-phrase-fixtures SPEECH_RESULT=/tmp/he-phrases.json node ../fresh/run.mjs
node summarize.mjs /tmp/he-phrases.json
```

## אתגר התיקונים

שישה משפטים חדשים הוקראו בשלושה קולות מלאכותיים, ללא רעש נוסף. כל דובר מלאכותי הקריא את התיקון ואת המילים שקדמו לו ברצף אחד. משפטים אחרים כוללים רק תחליף, כדי לבדוק אם ייכנס לתמליל מצרך מהמתכון שלא נאמר. האודיו הופק מקומית ב־Pocket TTS וב־Piper. המקורות והרישיונות רשומים בארכיון. [המשפטים והביטויים שנבדקו](corrections.json) · [18 קובצי השמע](corrections-wav.zip)

```sh
python prepare.py --corrections /tmp/he-correction-fixtures
SPEECH_RECIPE_HINTS=1 SPEECH_MANIFEST=/tmp/he-correction-fixtures/manifest.json \
  SPEECH_NEW_CACHE=/tmp/he-correction-fixtures SPEECH_RESULT=/tmp/he-corrections.json node ../fresh/run.mjs
node summarize.mjs --corrections /tmp/he-corrections.json
```

## שילוב המילה הבודדת והצירוף

נבדקה זרוע המשך אחת בעקבות ההבדל בין תוצאות המצרכים והתחליפים. היא מקבלת את כל שש צורות הבסיס. לשחזור מוסיפים `--combined` לסוף כל אחת משתי פקודות ההכנה, משתמשים בתיקיות יעד חדשות ומריצים כל מדגם עם `SPEECH_HINT_ARM=hints-cookies` נוסף על משתני הסביבה שלמעלה. להעברת תוצאות חדשות למסכם משתמשים ב־`node summarize.mjs --combined /tmp/he-phrases.json /tmp/he-both.json`. למדגם התיקונים מוסיפים גם `--corrections` ומעבירים את שני הקבצים המתאימים.
